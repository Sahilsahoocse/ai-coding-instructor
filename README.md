# AI Coding Instructor

An AI-powered Coding Instructor built with **Python, Gemini API, HTML, CSS, and JavaScript**. It helps users learn Data Structures, Algorithms, and programming concepts through an interactive web interface.

## 🚀 Features

- 💡 Answers DSA and coding questions using Gemini API.
- 📚 Provides detailed explanations and debugging help.
- 🌙 Modern dark-mode responsive UI.
- ⚡ Fast and interactive chat-based coding assistant.

## 🛠️ Tech Stack

- Python
- HTML5, CSS3, JavaScript
- Google Gemini API

## ▶️ How to Run

1. Clone the repository.
2. Add your Gemini API key in the project.
3. Run the Python backend.
4. Open `index.html` in your browser.

## 📌 Project Goal

A simple AI tutor that makes coding and DSA learning easier with real-time explanations and an intuitive interface.
